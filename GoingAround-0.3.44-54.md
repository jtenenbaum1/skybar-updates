# Going Around 0.3.44

- The Briefing's headline stories have a new look. Each story sits on a colored band: maroon when an illness is rising, blue when it is steady, green when it is easing. The top story's chart now has labeled axes and dates.
- Each story's numbers now appear as tiles under the band, such as ED visits, test positivity, admissions, wastewater and the national figure. Each tile shows the latest value and last week's value or the region, and its color follows the activity level. Click a tile to open that chart.
- An illness that already has a headline story no longer shows up again in Watching. A short line under Watching names the illnesses covered above.

These improvements are shared by Mac, iPhone and the web.
