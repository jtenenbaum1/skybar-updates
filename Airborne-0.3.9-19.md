# Airborne 0.3.9

- Trend map layers: choose Wastewater, ED visits, Hospital admissions and Test positivity in any combination. The map now shows where each is rising (orange ↗) and falling (blue ↘).
- Smaller, clearer markers: a compact pill for each local area and a badge for each state replace the large bubbles. The whole-US view shows every state plus the 40 largest local areas, so busy metros no longer pile up.
- A simpler legend, with a "How to read this map" button that explains fills, outlines, pills and badges.
- Test positivity uses CDC's 3-week average for COVID-19 and RSV. It isn't available for flu yet.
- When one CDC source doesn't load, that layer shows a warning and a Retry button, and the other layers keep working.
