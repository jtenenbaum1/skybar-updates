# Going Around 0.3.46

- The map's area details now give each measure its own card, with the measure's name in bold, so Wastewater, ED visits, Admissions and Positivity no longer run together.
- The details panel is now titled with the place you picked, such as "Montana" or "Baltimore · Baltimore City", instead of "Selected evidence".

The web map has the same cards, plus a smaller close button and Mac-style menus for Illness, Measure and Data areas.
