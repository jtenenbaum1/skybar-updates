# Going Around 0.3.47

- Local areas on the map now name the place in their details header: "Kings County, NY" for a single county, or "Montgomery – Prince Georges · Multi-county area, MD" when CDC's area covers several counties.
- Instead of a bare "Current sample unavailable", each measure now says why: "No sample since Sep 12" when the last sample is older, "No recent sampling in this area" when a local area has none, and "Reported for states only" for admissions and test positivity, which CDC doesn't report for local areas.

These changes are shared by Mac, iPhone and the web map.
