# Going Around 0.3.43

- HHS region borders on the Analyst map are now a single thin gray line, so the regions read clearly without competing with the state colors. Shared borders and coastlines are the same weight, and small islands no longer show as dark dots.
- Local wastewater areas now appear for about 30 more sites whose county CDC spells two ways, such as Saint Louis and St. Louis, or Prince Georges and Prince George's.
- Norovirus no longer appears in the watched-illness menu. It has no current data source, so ticking it only added an empty card.

These improvements are shared by Mac, iPhone and the web map.
